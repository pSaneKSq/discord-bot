# Текущая задача

Использовать систему как у музыкальных ботов (которые берут музыку с YouTube, Spotify и т.д.), но подменять файлы на локальные файлы, которые загружает пользователь.

**Суть**: Взять рабочую систему воспроизведения аудио как у популярных музыкальных ботов, но вместо URL ссылок на YouTube/Spotify использовать локальные MP3 файлы, загруженные пользователем.
